# Week 5 Assignments – JavaScript Arrays and Objects

## Overview

This repository contains my Week 5 assignments and practice exercises focused on JavaScript arrays, objects, and data manipulation.

## Topics Covered

- JavaScript arrays and objects
- Accessing and updating data
- Array methods
- Adding and removing elements
- The spread and rest operators
- Object and array manipulation
- Working with real-world data

## Projects and Exercises

- **Array and Object Drills:** Practicing JavaScript concepts through exercises.
- **Restaurant Dashboard:** Applying arrays, objects, and array methods to display restaurant orders, calculate revenue, and filter orders by status.

## Technologies Used

- HTML
- JavaScript
- Tailwind CSS
- Vite
- Git and GitHub

## How to Run the Project

1. Clone this repository.
2. Open the project folder in your terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.

The goal of these assignments is to improve my understanding of JavaScript fundamentals and apply them in practical projects.
